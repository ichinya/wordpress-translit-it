These screenshots show the unmodified Russian settings screen in version 1.9.1 on a disposable WordPress 7.1.3 demo installation with the administrator's language set to Russian.

Publish `screenshot-1.png`, `screenshot-2.png` and `screenshot-3.png` in the top-level `assets/` directory of the WordPress.org SVN repository. Their numbered captions are in the `Screenshots` section of `readme.txt`.

1. Local transliteration and sample address.
2. Yandex Cloud, saved-key status and fallback.
3. Legacy Yandex API and the preserved folder identifier.

All credentials and folder identifiers used in the demo are fictional. Screenshots are captured directly from WordPress; saved API keys are never displayed. This directory is excluded from the installation ZIP by the release builder.
